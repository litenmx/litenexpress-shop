Protección de Datos y Privacidad

Aviso de privacidad

Liten Express (Comercio Electrónico Liten), con domicilio físico en Constituyentes 3170, Col. Centro, C.P. 91700, Veracruz, Veracruz, es responsable del tratamiento legítimo y seguro de la información operativa recabada en sus servicios logísticos.

1. Datos que solicita el cotizador público

El formulario público de cotización solicita únicamente código postal de destino, colonia o población y dimensiones físicas del paquete (peso, largo, ancho y alto). Estos datos se emplean exclusivamente en el momento para consultar la tarifa estimada de transporte.

2. Datos que NO solicita el sitio público

  • No se solicitan números de tarjetas de crédito, débito, CVV ni cuentas bancarias.
  • No se exige registro de cuenta para los visitantes que consultan tarifas en el cotizador público.
  • No se comercializan ni ceden datos a terceros con fines publicitarios.

3. Uso de integraciones de Google APIs (Google Drive y Google Sheets)

Dentro de nuestro sistema operativo interno (sistema.litenexpress.shop), utilizado exclusivamente por personal autorizado de Liten Express, el sistema se integra con Google Drive API y Google Sheets API en la cuenta administrativa de la empresa con la única finalidad de:

  • Almacenar y respaldar en formato PDF las guías de envío y comprobantes oficiales de recepción generados en la operación diaria.
  • Registrar las bitácoras internas de ventas, folios de aliados comerciales y números de rastreo para control administrativo y atención al cliente.

El uso de la información recibida desde las APIs de Google cumple estrictamente con la Política de Datos del Usuario de los Servicios de API de Google (Google API Services User Data Policy), incluyendo los requisitos de Uso Limitado.

4. Contacto para asuntos de privacidad

Para cualquier duda o solicitud relacionada con este Aviso de Privacidad o el tratamiento de datos en sucursal, puedes comunicarte directamente a nuestro canal oficial: +52 229 667 6770 o al correo administrativo mxliten@gmail.com.

Compromiso de seguridad

Liten Express mantiene controles de acceso cifrados y limita la captura de información estrictamente a los datos indispensables para documentar y dar seguimiento a cada envío.
